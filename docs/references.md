# Research references

The following public repositories were reviewed as design-learning references. Their implementation details and feature claims belong to their respective authors; this project does not claim authorship of those repositories.

1. **stavanrupareliya36/uart-design-verification** — configurable TX/RX, multi-baud loopback, error-injection tests, waveform and open-source checks.
   https://github.com/stavanrupareliya36/uart-design-verification
2. **Meghana-0345/UART-controller-verilog** — selectable parity, framing-error detection, synchronizer and scoreboard-oriented testbench.
   https://github.com/Meghana-0345/UART-controller-verilog
3. **VLSI-Shubh/UART** — 16x oversampling receiver architecture and loopback testbench.
   https://github.com/VLSI-Shubh/UART
4. **ArwaKantoush/UART_Transmitter** — TX FSM decomposition, parity calculation and QuestaSim/ModelSim scripts.
   https://github.com/ArwaKantoush/UART_Transmitter
5. **Vatsal-024/uart-transceiver-verilog** — modular baud generator, TX/RX and loopback structure.
   https://github.com/Vatsal-024/uart-transceiver-verilog
